SMS/GG Graphics Exporter

Aseprite Tool • Graphics Data Converter • SMS & Game Gear

Convert Aseprite files into data that can be used to create graphics on the Sega Master System and Sega Game Gear! With a special feature utilizing Aseprite's slice feature, you can now set the priority, sprite palette, and software flag bits on a per-tile basis!
