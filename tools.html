SG-1000 Graphics Exporter

Aseprite Tool • Graphics Data Converter • SG-1000/MSX

Convert Aseprite files into data to be used in SG-1000 and MSX games! This script takes an image designed in Aseprite and, as long as the image obeys the graphical limitations of the SG-1000, it is converted into three .inc files that can be imported into SG-1000 projects for quick graphics implementation!
